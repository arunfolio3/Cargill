# HL+ Economics Calculator

Single-page dairy economics calculator. Enter Farm and What If values in **HL+ Economics: Required data**; the page calculates:

- Farm's Efficiency Indicators
- Profit & Loss Statement (Farm P&L)
- Profit & Loss Statement / Milking Cows (By Business P&L)

Everything lives in `index.html` (no build step, no dependencies). Open it in a browser or serve the folder from any static host.

Features: editable scenario names, collapsible sections with Expand all / Collapse all, numeric-only inputs with thousands separators, reset to blank inputs, and print layout with footer.
