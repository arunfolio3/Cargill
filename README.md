# Cargill

Client tools hosted on GitHub Pages. Each project lives in its own folder.

| Project | Link |
|---|---|
| HL+ Economics Calculator | https://arunfolio3.github.io/Cargill/economics-calculator/ |
| Dairy Lifetime Tree | https://arunfolio3.github.io/Cargill/lifetime-tree/ |

## HL+ Economics Calculator

Single-page dairy economics calculator. Enter Farm and What If values in **HL+ Economics: Required data**; the page calculates Farm's Efficiency Indicators, Farm P&L and By Business P&L. Everything lives in `economics-calculator/index.html` (no build step, no dependencies).

## Dairy Lifetime Tree

Single-page Lifetime Tree calculator. Enter the Current and What If scenarios on the tree (editable boxes; linked boxes recalculate upward to Herd Lifetime Productivity), then use **Compare** to see both scenarios on one tree. Prints on one A4 portrait page. Everything lives in `lifetime-tree/index.html` (no build step, no dependencies).
